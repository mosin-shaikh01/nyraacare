# Nyarracare Theme

A custom WordPress theme for the Nyarracare healthcare services website.

## Features

- Responsive design with mobile-first approach
- Custom logo support
- Featured images support
- Primary and footer navigation menus
- Widget-ready sidebar
- Full HTML5 markup
- Post navigation and pagination
- Comment support
- 404 error page

## Installation

1. Upload the theme folder to `wp-content/themes/`
2. Activate the theme from the WordPress admin dashboard (Appearance > Themes)

## Structure

- `style.css` - Main stylesheet and theme metadata
- `functions.php` - Theme setup and WordPress hooks
- `header.php` - Header template
- `footer.php` - Footer template
- `index.php` - Main template file
- `single.php` - Single post template
- `page.php` - Page template
- `comments.php` - Comments template
- `404.php` - 404 error page template

## Customization

### Adding a Custom Logo

1. Go to Appearance > Customize
2. Click on "Site Identity"
3. Upload your logo image
4. Save

### Adding Navigation Menus

1. Go to Appearance > Menus
2. Create a new menu
3. Add pages/posts to the menu
4. Assign the menu to either "Primary Menu" or "Footer Menu" location

### Adding Widgets

1. Go to Appearance > Widgets
2. Add widgets to the "Primary Sidebar" area
